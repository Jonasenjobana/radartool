# 领域文档

本项目采用 single-context 布局：
根目录 `GLOSSARY.md` 保存领域术语，
`docs/adr/` 保存架构决策。

## 阅读时机

探索代码前，阅读根目录 `GLOSSARY.md`，
以及 `docs/adr/` 中与当前任务有关的决策。

这些文件尚不存在时直接继续。
由 `domain-modeling` 在术语或决策明确后按需创建，
无需预先创建占位文档。

## 术语与决策

- 在任务标题、设计说明、假设和测试名称中，
  使用术语表定义的词汇。
- 所需概念尚未收录时，先核对项目已有用语；
  确有缺口时交由 `domain-modeling` 补充。
- 方案与已有 ADR 冲突时，明确指出对应决策、
  冲突内容及重新讨论的理由。
